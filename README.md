# Math Town — My Little Woodland Room

5~7세 어린이를 위한 **수학 놀이 + 숲속 방 꾸미기** 웹 게임입니다.
수학 놀이를 하면 마을 재료(도토리, 사과 …)를 모으고, 공방에서 재료로 가구를 만들어 나만의 방을 꾸밉니다.

- 기본 언어는 영어, 설정에서 한국어를 고를 수 있습니다.
- 광고·결제·개인정보 수집이 없습니다. 진행 상황은 이 기기(브라우저)에만 저장됩니다.
- 틀려도 벌칙이 없습니다. 관찰 → 직접 해 보기 → 시범 순서로 힌트를 줍니다.

## 바로 실행하기

필요한 것: [Node.js](https://nodejs.org/) 18 이상 (20 이상 권장)

```bash
npm install      # 처음 한 번만: 필요한 패키지 설치
npm run dev      # 개발 서버 실행 → 터미널에 나오는 주소를 브라우저로 열기
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버. 코드를 고치면 화면이 바로 바뀝니다 |
| `npm run typecheck` | 타입 검사만 (번역 키 누락도 여기서 잡힙니다) |
| `npm run build` | 타입 검사 + 배포용 파일 만들기 → `dist/` 폴더 |
| `npm run preview` | 만든 배포용 파일을 미리 보기 |
| `npm test` | 자동 테스트 (아래 '테스트' 참고) |

**공개 주소: https://nyamnuki.github.io/apple_pie/** — `main` 이 바뀌면 GitHub Actions 가 자동으로 다시 배포합니다.
배포 방법 자세히: [docs/DEPLOY.md](docs/DEPLOY.md)

## 게임 구성

| 화면 | 내용 |
|---|---|
| 타이틀 | 루루와 친구들(도토·모모)이 반겨 줍니다. 설정 버튼 |
| 내 방 | 아이소메트릭 방. 루루가 지금 하면 좋은 것을 말해 줌. '루루의 질문'(왼쪽 위 버튼)으로 내 방 물건 세기, 카메라(오른쪽 위)로 방 사진을 그림 파일로 저장(나무 액자, 아래에 '나만의 숲속 방 · 날짜'). 기기 시계에 따라 낮·저녁(노을)·밤(달과 별, 조명 빛 — 조명을 누르면 끄고 켬) 분위기, 날짜에 따라 창밖 계절(벚꽃·여름 숲·단풍·눈). 놀이하기 · 방 꾸미기 · 공방 · 내 가방 · 스티커 도감 |
| 지도 | 맨 위 '오늘의 문제'(날마다 끝낸 놀이에서 한 문제, 맞히면 도장, 도장 3개마다 황금 도토리, 이틀 이상 이어 풀면 '○일 연속'). 마을마다 풍경 그림(도토리 마을·달빛 숲·수정 동굴)과 그 사이 오솔길. 잠긴 마을은 안개와 자물쇠, 놀이를 모두 끝낸 마을은 리본과 '모두 끝냈어요'. 마을 고르기. 도토리 마을 놀이를 2개 끝내면 달빛 숲, 달빛 숲 놀이를 2개 끝내면 수정 동굴, 수정 동굴 놀이를 2개 끝내면 햇살 들판, 햇살 들판 놀이를 2개 끝내면 바람 언덕, 바람 언덕 놀이를 2개 끝내면 무지개 호수가 열립니다 |
| 수학 놀이 | 도토리 마을 5개: 사과 세기, 어느 쪽이 더 많을까?, 더하기, 빼기, 몇 개 더 많을까?(위아래로 짝지어 남는 수) / 달빛 숲 3개: 다음에 올 것은?(규칙), 도형 찾기, 얼마나 길까?(블록으로 길이 재기) / 수정 동굴 3개: 2씩 뛰어 세기, 5씩 뛰어 세기(주사위 눈 모양 묶음), 10씩 묶어 세기(50까지) / 햇살 들판 3개: 수직선 뛰기(더하기·빼기), 짝이 될까 하나 남을까?(짝수·홀수), 10 만들기(10칸 상자의 빈칸 채우기) / 바람 언덕 2개: 몇 시일까?(정각), 30분 / 무지개 호수 2개: 똑같이 나누기(하나씩 번갈아 두 친구 접시에), 호수에 비친 두 배(물에 비친 모습으로 이어 세기). 해 본 놀이는 체크, '해 보기'를 한 번에 맞힌 적이 있으면 별. 위쪽에 그 마을 안내 친구의 마을 소개 말풍선(읽어 주기). 놀이 카드마다 '이름 듣기' 스피커(공방 가구 이름에도) |
| 놀이 진행 | 6단계: 살펴보기 → 만져 보기 → 예상하기 → 확인하기 → 발견하기 → 해 보기. 처음에는 정해진 문제, **다시 하면 예상하기·해 보기의 수가 바뀝니다** (`src/features/math/variation.ts`). 예상하기부터는 위쪽 '다시 보기'로 살펴보기 시범을 다시 볼 수 있음 |
| 보상 | 받은 재료를 크게 보여주고, 발견한 원리를 다시 짚어 줍니다. 새 스티커를 누르면 크게 보기. 그 마을 놀이를 처음 모두 끝내면 리본과 축하. 아직 안 한 놀이가 있으면 '다음 놀이: 이름' 버튼(같은 마을 먼저) |
| 공방 | 도토가 안내합니다. 재료로 가구 만들기 (가진 수 / 필요한 수 표시, 아직 못 가는 마을 재료는 자물쇠). 맨 위 '다음 목표': 곧 만들 수 있는 가구, 더 필요한 재료, 그 재료를 주는 놀이 (`src/features/workshop/nextGoal.ts`) |
| 내 가방 | 모은 재료와 가진 가구. 재료마다 '더 얻는 곳'(그 재료를 주는 놀이, 황금 도토리는 오늘의 문제 도장) |
| 스티커 도감 | 놀이를 끝낼 때마다 그 마을 스티커 한 장 (마을마다 6장, 모두 36장). 아직 없는 칸은 점선과 '?'. 마을 6장을 다 모으면 금테두리와 리본 '다 모았어요!'. 모은 스티커를 누르면 크게 보기(이름 읽어 주기, 받은 마을, 화살표·←→ 로 넘기기, Esc 로 닫기). 맨 위 '루루 옷장': 스티커 4·7·11·18·24·30장에 모자·스카프가 하나씩 열리고, 고른 옷은 모든 화면의 루루가 입음 (`src/features/outfits/`) |
| 반려 친구 | 스티커 3·9·15·21장을 모으면 아기 오리 두두·아기 여우 보리·아기 부엉이 후·아기 거북 콩콩이 방에 찾아와 빈 칸을 걸어 다님 (움직임 줄이기면 가만히). 누르면 폴짝 (자동 읽기를 켰으면 '○○, 안녕!' 하고 이름을 불러 줌) |
| 방 꾸미기 | 가구 놓기 · 옮기기 · 돌리기 · 치우기 · 색 바꾸기(3가지), 모두 치우기(한 번 더 묻고, 치운 뒤 '다시 원래대로'), 되돌리기(방 왼쪽 위, 방금 바꾼 것 하나), 벽지 붙이기, 벽 장식 걸기(액자·가랜드) |
| 설정 | 언어 선택, 효과음·배경 음악·읽어 주기(말풍선, 물건을 셀 때 '하나, 둘, 셋')·읽어 주는 빠르기(천천히/보통)·큰 글씨 켜기/끄기, 저장 상태, 어른 전용 |
| 어른 설정 | 곱셈 2문제를 연속으로 맞혀야 열림. 개인정보 안내, 진행 요약, 이번 주 놀이(최근 7일 날짜별 끝낸 놀이 수 막대), 놀이별 기록(한 횟수·한 번에 맞힌 횟수·본 힌트·마지막으로 한 때), 함께 해 보면 좋은 놀이(힌트를 많이 본 놀이 3개까지), 쉬어 가기 알림(끔·15·20·30분), 백업(파일로 저장·파일에서 되살리기), 홈 화면에 추가하기(기기별 안내), 진행 상황 지우기 |
| 마을별 음악·안내 | 도토리 마을: 루루·낮의 곡 / 달빛 숲: 모모·밤의 곡 / 수정 동굴: 도토·동굴 곡 / 햇살 들판: 루루·낮의 곡 / 바람 언덕: 모모·낮의 곡 |

### 휴대폰 홈 화면에 설치하기 (인터넷 없이 쓰기)
- **아이폰(사파리)**: 사이트를 연 뒤 공유 버튼 → '홈 화면에 추가'
- **안드로이드(크롬)**: 사이트를 연 뒤 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'
- 한 번 열어 두면 그다음부터는 인터넷이 없어도 열립니다. 새 버전을 배포하면 인터넷에 연결된 상태에서 앱을 다시 열 때 저절로 바뀝니다.
- 만드는 곳: `public/manifest.webmanifest`(이름·아이콘), `public/icons/`(아이콘, 원본 `icon.svg`), `build/offline.ts`(빌드할 때 `sw.js` 를 만들어 이번 빌드 파일을 모두 저장해 둠)
- 진행 상황은 여전히 이 기기(localStorage)에만 저장됩니다. 서버로 보내는 것은 없습니다.

## 자주 하는 작업

### 문구(번역) 고치기
- 화면 문구는 모두 `src/i18n/locales/en.ts`(영어)와 `ko.ts`(한국어)에 있습니다.
- 새 문구는 두 파일에 **같은 키**로 넣습니다. 한쪽에 빠뜨리면 `npm run build` 가 오류로 알려줍니다.
- 화면 코드에서는 `t('menu.play')` 처럼 키로 불러 씁니다. 숫자는 `{n}` 처럼 자리를 두고 채웁니다.
- 한국어는 `{n}` 바로 뒤에 조사(이/가, 을/를)가 오지 않게 써야 어떤 숫자가 와도 자연스럽습니다.

### 수학 놀이 추가하기
1. `src/types/math.ts` 의 `LessonId` 에 새 id 추가
2. `src/data/math/lessons.ts` 에 장면(수량)·선택지·보상 재료 추가 — 정답은 수량으로 자동 계산
3. `en.ts`, `ko.ts` 의 `lessons` 에 같은 id 로 문장 12개 추가 (빠뜨리면 빌드가 알려줍니다)

### 다시 할 때 바뀌는 문제
- 처음 하는 판은 `lessons.ts` 그대로이고, 2번째 판부터 '예상하기'·'해 보기'의 수가 바뀝니다. 몇 번째 판인지는 놀이 기록(`lessonStats.plays`)으로 정합니다.
- 같은 판 번호면 언제나 같은 문제이고, 바로 앞 판과 같은 답은 나오지 않습니다.
- 난이도 범위와 가르치는 점은 그대로입니다.
  - 비교의 '똑같다'는 계속 똑같게
  - 더하기는 10을 넘게, 빼기는 10 아래로
  - 10씩 묶기는 묶음 3~4개
- 선택지에는 아이가 하기 쉬운 실수를 넣습니다 (자리 바꿔 읽기, 혼자인 것 빼먹기 등).
- 바꾸지 않는 것: 살펴보기·만져 보기 장면, 규칙 찾기 (문장이 그 장면을 그대로 설명하기 때문).
- 범위는 `variation.ts` 의 `varyScene` 에서 고칩니다. `variation.test.ts` 가 판 200개씩 만들어 정답·범위·문장 자리를 검사합니다.

### 마을 추가하기
1. `src/types/resources.ts` 의 `RegionId` 와 `ResourceId` 에 마을과 재료 id 추가
2. `src/data/regions/regions.ts` 에 열리는 조건(`unlock`), `src/data/resources/resources.ts` 에 재료 추가
3. 지도 카드 색(`RegionMapScreen.tsx` 의 `CARD_STYLE`), 안내 친구(`LessonScreen.tsx` 의 `GUIDE_OF`), 음악(`App.tsx`, `music.ts`)을 정한다 — 빠뜨리면 빌드가 알려줍니다
4. 그 마을의 놀이와 가구를 추가하고, 언어 파일에 이름을 넣는다

### 가구 추가하기
1. `src/data/furniture/furniture.ts` 에 한 줄 추가 — 얻는 방법(처음부터 가짐 / 레시피)과 그림이 없을 때 그릴 모양(`placeholder.shape`)
2. `en.ts`, `ko.ts` 의 `furniture` 에 이름과 설명 추가
3. (선택) `public/assets/furniture/` 에 그림 넣기 — 없으면 코드로 그린 가구 모양이 보입니다

### 보상·레시피 숫자 조정
- 놀이마다 받는 재료: `src/data/math/lessons.ts` 의 `rewards`, 처음 끝냈을 때 보너스: `firstTimeBonus`
- 가구 레시피: `src/data/furniture/furniture.ts` 의 `unlockCondition`
- 마을 열림 조건: `src/data/regions/regions.ts` 의 `unlock` (예: 도토리 마을 놀이 2개). 닫힌 마을 재료가 필요한 가구는 자물쇠로 보입니다.

### 벽 장식 추가하기
`furniture.ts` 에 `category: 'wall'` 로 추가하고 `wallBand`(가운데 `middle` / 위쪽 `high`)와 차지하는 칸 수(`gridWidth`)를 정합니다.
오른쪽 벽 창문 자리(2~3번 칸)의 가운데 높이에는 걸 수 없습니다 (`src/features/room/placement.ts`).

### 꾸미기 화면의 동작
- 방 오른쪽 아래 돋보기 버튼(또는 두 손가락 벌리기)으로 방을 크게 보고, 한 손가락으로 밀어 둘러봅니다. 오므리거나 다시 누르면 방 전체 보기 (`ZoomableRoom.tsx`).
- 놓을 수 있는 칸은 연한 초록 + `+` 표시 (색만으로 알리지 않음). 마우스나 키보드로 칸을 가리키면 놓일 모습을 반투명하게 미리 보여 줍니다.
- 놓을 수 없는 칸을 누르면 **저절로 옆에 놓지 않고**, 가장 가까운 빈 자리를 반짝이는 미리 보기로 권한 뒤 '여기에 놓기'를 눌러야 놓입니다. 다른 빈 칸을 눌러도 됩니다.
- 자리 고르는 동안 아래에 지금 놓는 물건의 그림과 이름이 보입니다. 놓으면 바닥에서 빛이 한 번 퍼지고, 돌릴 자리가 없으면 가구가 좌우로 흔들립니다.
- 방의 바닥 가구를 고르면 같은 가구를 3가지 색으로 보여 주는 버튼이 나옵니다. 고른 색은 방·사진에 그대로 쓰입니다 (`src/features/room/tints.ts`, 방은 SVG 필터 `#tint-1`·`#tint-2`, 목록 그림은 같은 각도의 CSS `hue-rotate`).
- 관련 파일: `src/features/room/decorate/DecorateScreen.tsx`, `PlacingPanel.tsx`, `src/features/room/RoomView.tsx`, `FurnitureSprite.tsx`(`FurnitureGhost`), `WallItemSprite.tsx`(`WallGhost`)

### 방 배치 규칙은 한 곳에서
방을 바꾸는 모든 동작(놓기·옮기기·돌리기·치우기·벽에 걸기·벽지)은 `src/features/room/roomState.ts` 의 `applyRoomAction` 을 거칩니다.
방 밖, 다른 가구와 겹침, 가진 개수보다 많이 놓기, 창문 자리 같은 잘못된 요청은 상태를 전혀 바꾸지 않습니다.
화면에서 미리 막지 못한 경우(예: 아이가 같은 칸을 아주 빠르게 두 번 누름)에도 여기서 한 번 더 막습니다.

### 효과음·배경 음악 바꾸기
- 효과음: `src/services/audio/sound.ts` 에 소리마다 음 높이·길이가 적혀 있습니다.
- 배경 음악: `src/services/audio/music.ts` 에 곡 2개(낮의 숲 / 밤의 숲)의 빠르기·화음·멜로디가 음 이름(`E4 - G4 …`)으로 적혀 있습니다.
  어느 화면에서 어떤 곡이 나올지는 `src/app/App.tsx` 의 `track` 에서 정합니다.
- 음원 파일은 쓰지 않고 모두 코드로 연주합니다. 음악은 아이가 화면을 처음 누른 뒤에 시작하고, 다른 앱으로 넘어가면 멈춥니다.

### 그림 바꾸기
`public/assets/` 아래에 정해진 이름으로 그림을 넣기만 하면 됩니다. 코드는 바꾸지 않습니다.
파일 이름, 각도·조명·크기 규칙은 [public/assets/README.md](public/assets/README.md) 에 있습니다.

## 저장

브라우저(localStorage)에 저장합니다. 서버로 보내는 데이터는 없습니다.

| 키 | 내용 |
|---|---|
| `mathTown.locale` | 선택한 언어 (게임 데이터와 따로 저장) |
| `mathTown.settings` | 효과음·배경 음악 켜기/끄기 |
| `mathTown.save` | 재료, 가구, 끝낸 놀이, 방 배치(바닥 가구·벽 장식·벽지) + `schemaVersion`(현재 2), 저장 시각 |
| `mathTown.save.backup` | 읽을 수 없던 저장본을 버리지 않고 보관한 것 |

- 바뀐 뒤 0.3초 후 저장하고, 창을 닫거나 다른 앱으로 넘어갈 때 바로 저장합니다.
- 저장본이 깨졌거나 모르는 버전이면 처음 상태로 시작하고, 원래 내용은 backup 에 남깁니다.
- 일부만 이상하면(없는 가구, 음수, 방 밖 위치 등) 그 부분만 버리고 나머지는 살립니다 (`src/services/storage/sanitize.ts`).
- **저장 데이터 모양을 바꿀 때:** `src/services/storage/gameSave.ts` 의 `SCHEMA_VERSION` 을 1 올리고,
  `MIGRATIONS` 에 옛 버전 → 새 버전 변환 방법을 추가합니다. 그래야 기존 사용자의 진행 상황이 유지됩니다.
  (예: 버전 1 → 2 에서 벽 장식 `wallItems` 를 빈 목록으로 추가)

## 접근성과 화면 크기

- 버튼·누르기 영역은 최소 48px. 휴대폰에서 바닥 칸이 작아서, 놓을 수 없는 칸을 누르면 바로 옆 빈 칸에 놓아 줍니다.
- 글자 대비: 글자를 올리는 나무색은 `wood`(#946539, 대비 4.6). 기획서의 Oak Wood(`oak`)는 방·가구 그림과 테두리에만 씁니다.
- 색만으로 상태를 알리지 않습니다 (✓·✕, 점선, 반짝이 표시를 함께 사용).
- 화면이 바뀌면 제목으로 초점이 옮겨져 화면 읽기 프로그램이 새 화면 이름을 읽어 줍니다.
- 휴대폰을 눕힌 화면(높이 500px 이하)에서는 놀이·타이틀·보상·어른 확인 화면이 두 칸으로 배치됩니다.
- 두 번 톡 눌러 확대되는 것은 막고, 두 손가락 확대는 시력이 약한 사용자를 위해 허용합니다.
- "움직임 줄이기" 설정을 켠 기기에서는 애니메이션이 꺼집니다.
- 예상하지 못한 오류가 나면 하얀 화면 대신 '다시 시작하기' 화면이 나옵니다.
