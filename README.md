# Math Town — My Little Woodland Room

5~7세 어린이를 위한 **수학 놀이 + 숲속 방 꾸미기** 웹 게임입니다.
수학 놀이를 하면 마을 재료(도토리, 사과 …)를 모으고, 공방에서 재료로 가구를 만들어 나만의 방을 꾸밉니다.

- 기본 언어는 영어, 설정에서 한국어를 고를 수 있습니다.
- 광고·결제·개인정보 수집이 없습니다. 진행 상황은 이 기기(브라우저)에만 저장됩니다.
- 틀려도 벌칙이 없습니다. 관찰 → 직접 해 보기 → 시범 순서로 힌트를 줍니다.

## 바로 실행하기

필요한 것: [Node.js](https://nodejs.org/) 18 이상 (20 이상 권장)

```bash
npm install      # 처음 한 번만: 필요한 패키지 설치
npm run dev      # 개발 서버 실행 → 터미널에 나오는 주소를 브라우저로 열기
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버. 코드를 고치면 화면이 바로 바뀝니다 |
| `npm run typecheck` | 타입 검사만 (번역 키 누락도 여기서 잡힙니다) |
| `npm run build` | 타입 검사 + 배포용 파일 만들기 → `dist/` 폴더 |
| `npm run preview` | 만든 배포용 파일을 미리 보기 |
| `npm test` | 자동 테스트 (아래 '테스트' 참고) |

배포(인터넷에 올리기) 방법은 [docs/DEPLOY.md](docs/DEPLOY.md) 를 보세요.

## 게임 구성

| 화면 | 내용 |
|---|---|
| 타이틀 | 루루가 반겨 줍니다. 설정 버튼 |
| 내 방 | 아이소메트릭 방. 놀이하기 · 방 꾸미기 · 공방 · 내 가방 |
| 지도 | 마을 고르기. 도토리 마을 놀이를 2개 끝내면 달빛 숲이 열립니다 |
| 수학 놀이 | 도토리 마을 4개: 사과 세기, 어느 쪽이 더 많을까?, 더하기, 빼기 / 달빛 숲 2개: 다음에 올 것은?(규칙), 도형 찾기 |
| 놀이 진행 | 6단계: 살펴보기 → 만져 보기 → 예상하기 → 확인하기 → 발견하기 → 해 보기 |
| 보상 | 받은 재료를 크게 보여주고, 발견한 원리를 다시 짚어 줍니다 |
| 공방 | 재료로 가구 만들기 (가진 수 / 필요한 수 표시, 아직 못 가는 마을 재료는 자물쇠) |
| 내 가방 | 모은 재료와 가진 가구 |
| 방 꾸미기 | 가구 놓기 · 옮기기 · 돌리기 · 치우기, 벽지 붙이기 |
| 설정 | 언어 선택, 저장 상태, 어른 전용 |
| 어른 설정 | 곱셈 2문제를 연속으로 맞혀야 열림. 개인정보 안내, 진행 요약, 진행 상황 지우기 |

## 자주 하는 작업

### 문구(번역) 고치기
- 화면 문구는 모두 `src/i18n/locales/en.ts`(영어)와 `ko.ts`(한국어)에 있습니다.
- 새 문구는 두 파일에 **같은 키**로 넣습니다. 한쪽에 빠뜨리면 `npm run build` 가 오류로 알려줍니다.
- 화면 코드에서는 `t('menu.play')` 처럼 키로 불러 씁니다. 숫자는 `{n}` 처럼 자리를 두고 채웁니다.
- 한국어는 `{n}` 바로 뒤에 조사(이/가, 을/를)가 오지 않게 써야 어떤 숫자가 와도 자연스럽습니다.

### 수학 놀이 추가하기
1. `src/types/math.ts` 의 `LessonId` 에 새 id 추가
2. `src/data/math/lessons.ts` 에 장면(수량)·선택지·보상 재료 추가 — 정답은 수량으로 자동 계산
3. `en.ts`, `ko.ts` 의 `lessons` 에 같은 id 로 문장 12개 추가 (빠뜨리면 빌드가 알려줍니다)

### 가구 추가하기
1. `src/data/furniture/furniture.ts` 에 한 줄 추가 — 얻는 방법(처음부터 가짐 / 레시피)과 그림이 없을 때 그릴 모양(`placeholder.shape`)
2. `en.ts`, `ko.ts` 의 `furniture` 에 이름과 설명 추가
3. (선택) `public/assets/furniture/` 에 그림 넣기 — 없으면 코드로 그린 가구 모양이 보입니다

### 보상·레시피 숫자 조정
- 놀이마다 받는 재료: `src/data/math/lessons.ts` 의 `rewards`, 처음 끝냈을 때 보너스: `firstTimeBonus`
- 가구 레시피: `src/data/furniture/furniture.ts` 의 `unlockCondition`
- 마을 열림 조건: `src/data/regions/regions.ts` 의 `unlock` (예: 도토리 마을 놀이 2개). 닫힌 마을 재료가 필요한 가구는 자물쇠로 보입니다.

### 그림 바꾸기
`public/assets/` 아래에 정해진 이름으로 그림을 넣기만 하면 됩니다. 코드는 바꾸지 않습니다.
파일 이름, 각도·조명·크기 규칙은 [public/assets/README.md](public/assets/README.md) 에 있습니다.

## 폴더 구조

```
src/
  app/            화면 전환(App), 타이틀, 플레이어 상태(gameState), 자동 저장, 오류 화면
  components/     여러 화면에서 같이 쓰는 부품 (버튼, 틀, 재료 표시, 캐릭터)
  features/
    room/         내 방, 아이소메트릭 방 그리기, 배치 규칙, 가구 모양 그림, 방 꾸미기(decorate/)
    map/          마을 지도
    math/         수학 놀이: 놀이 고르기, 6단계 진행, 힌트, 장면(fields/: 세기·비교·더하기·빼기·규칙·도형)
    rewards/      보상 화면
    workshop/     공방
    inventory/    내 가방
    settings/     설정, 언어 선택, 어른 확인, 어른 설정
  data/           게임 내용 데이터 (놀이, 가구, 재료, 마을, 캐릭터, 그림 경로)
  i18n/           다국어 시스템과 언어 파일 (locales/en.ts, ko.ts)
  services/       저장·불러오기·복구(storage/), 그림 파일 확인(assets/)
  styles/         색상 변수와 공통 스타일
  types/          데이터 모양 정의
  utils/          작은 계산 도우미
public/assets/    그림 파일 넣는 곳
tests/            자동 테스트
docs/             배포 안내
```

게임 내용(데이터), 문구(언어 파일), 그림(에셋), 규칙(로직)을 서로 다른 곳에 두어서
하나를 바꿔도 다른 것을 건드리지 않게 했습니다.

## 저장

브라우저(localStorage)에 저장합니다. 서버로 보내는 데이터는 없습니다.

| 키 | 내용 |
|---|---|
| `mathTown.locale` | 선택한 언어 (게임 데이터와 따로 저장) |
| `mathTown.save` | 재료, 가구, 끝낸 놀이, 방 배치 + `schemaVersion`, 저장 시각 |
| `mathTown.save.backup` | 읽을 수 없던 저장본을 버리지 않고 보관한 것 |

- 바뀐 뒤 0.3초 후 저장하고, 창을 닫거나 다른 앱으로 넘어갈 때 바로 저장합니다.
- 저장본이 깨졌거나 모르는 버전이면 처음 상태로 시작하고, 원래 내용은 backup 에 남깁니다.
- 일부만 이상하면(없는 가구, 음수, 방 밖 위치 등) 그 부분만 버리고 나머지는 살립니다 (`src/services/storage/sanitize.ts`).
- **저장 데이터 모양을 바꿀 때:** `src/services/storage/gameSave.ts` 의 `SCHEMA_VERSION` 을 1 올리고,
  `MIGRATIONS` 에 옛 버전 → 새 버전 변환 방법을 추가합니다. 그래야 기존 사용자의 진행 상황이 유지됩니다.

## 접근성과 화면 크기

- 버튼·누르기 영역은 최소 48px. 휴대폰에서 바닥 칸이 작아서, 놓을 수 없는 칸을 누르면 바로 옆 빈 칸에 놓아 줍니다.
- 글자 대비: 글자를 올리는 나무색은 `wood`(#946539, 대비 4.6). 기획서의 Oak Wood(`oak`)는 방·가구 그림과 테두리에만 씁니다.
- 색만으로 상태를 알리지 않습니다 (✓·✕, 점선, 반짝이 표시를 함께 사용).
- 화면이 바뀌면 제목으로 초점이 옮겨져 화면 읽기 프로그램이 새 화면 이름을 읽어 줍니다.
- 휴대폰을 눕힌 화면(높이 500px 이하)에서는 놀이·타이틀·보상·어른 확인 화면이 두 칸으로 배치됩니다.
- 두 번 톡 눌러 확대되는 것은 막고, 두 손가락 확대는 시력이 약한 사용자를 위해 허용합니다.
- "움직임 줄이기" 설정을 켠 기기에서는 애니메이션이 꺼집니다.
- 예상하지 못한 오류가 나면 하얀 화면 대신 '다시 시작하기' 화면이 나옵니다.

## 테스트

`npm test` 는 배포용으로 빌드한 뒤 실제 브라우저(Chromium)로 게임을 직접 조작해 확인합니다.
처음 한 번은 테스트용 브라우저를 내려받아야 합니다:

```bash
npx playwright install chromium
npm test
```

| 파일 | 확인하는 것 |
|---|---|
| `tests/i18n.spec.ts` | 처음엔 영어, 한국어로 즉시 전환, 다시 열어도 유지, 잘못된 값은 영어로, 한국어 화면에 영어 섞임 없음 |
| `tests/math.spec.ts` | 놀이 4종 전체 진행, 예상 비교, 힌트 3단계, 정답, 보상 화면, 한국어 진행 |
| `tests/rewards.spec.ts` | 보상 재료, 처음 보너스 1번만, 공방에서 만들기, 방에 놓기, 가방 |
| `tests/room.spec.ts` | 놓기, 겹침 막기, 옆 칸 보정, 옮기기·돌리기·치우기, 저장 |
| `tests/save.spec.ts` | 즉시 저장, 저장 시각 표시, 깨진/모르는 버전/일부 이상한 저장본 복구, 저장이 막힌 브라우저 |
| `tests/moonlight.spec.ts` | 달빛 숲 잠금·열림, 규칙 찾기·도형 찾기 놀이, 달빛 숲 재료 가구, 한국어 |
| `tests/parent.spec.ts` | 어른 확인, 진행 상황 지우기(언어 유지), 오류 화면 |
| `tests/layout.spec.ts` | 2개 언어 × 4개 화면 크기: 가로 넘침·글자 잘림·48px 미만 버튼 없음 |
