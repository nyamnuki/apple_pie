# 이미지 교체 안내

지금은 모든 그림이 emoji 로 대체되어 있습니다.
`src/assets/images.js` 에 적힌 경로대로 이 폴더에 파일을 넣으면 자동으로 실제 이미지로 바뀝니다.
(파일이 없으면 emoji 로 다시 돌아갑니다.)

- regions/    지역 카드·배경 (acorn-village.png …)
- resources/  자원 아이콘 (apple.png …)
- buildings/  건물 레벨별 그림 (acorn-burrow-1.png …)
- characters/ 마스코트
- ui/         타이틀 로고, 배경 등
