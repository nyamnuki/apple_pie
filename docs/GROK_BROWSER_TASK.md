# 셈셈마을 그림 만들기 — 클로드 웹에 붙여 넣을 지시문

아래 '지시문' 부분 전체를 클로드 웹(브라우저를 조작할 수 있는 클로드)에 붙여 넣으세요.
그림 46장(물건·재료 41장 + 루루 표정 5장)을 그록에서 만들어 PC 의 로드투리즈 폴더 안에 정해진 이름으로 저장하게 합니다.

- 먼저 **1단계(시범 5장)만** 시키고, 결과를 보고 괜찮으면 2단계를 시키는 것을 추천합니다.
- 다 되면 폴더의 그림을 이 대화(셈셈마을 작업)에 올려 주세요. 흰 바탕 지우기·크기 맞추기·게임에 넣기는 제가 합니다.

---

## 지시문 (여기부터 복사)

너는 지금부터 내 PC 의 브라우저에서 **그록(grok.com)** 으로 아이용 수학 게임 '셈셈마을'의 그림을 만들어 저장하는 일을 한다. 아래 규칙을 지켜 한 장씩 차례로 진행해.

### 저장 위치와 파일 이름
- 저장 폴더: 내 PC 의 **로드투리즈** 폴더 안에 `셈셈마을_그림` 폴더를 만들고, 그 안에 `items`, `characters` 두 폴더를 만든다.
  - 예: `로드투리즈/셈셈마을_그림/items/apple.png`, `로드투리즈/셈셈마을_그림/characters/lulu-default.png`
- 파일 이름은 아래 표의 **파일** 칸 그대로 (소문자, 붙임표 `-`, 확장자 `.png`). 이름을 바꾸거나 한국어로 쓰지 않는다.
- 그록이 jpg·webp 로 내려주면 그대로 두되 이름만 맞춘다 (예: `apple.jpg`). 확장자는 바꾸지 않아도 된다.
- 같은 그림을 다시 뽑아 바꿀 때는 덮어쓴다.

### 그록에서 그리는 방법
1. grok.com 에 로그인된 상태로 이미지 만들기(Imagine)를 연다. 화면 비율을 고를 수 있으면 **정사각형(1:1)**, 캐릭터는 **세로(4:5 또는 3:4)**.
2. 아래 표의 **지시문**과 **공통 문구**를 이어 붙여 그대로 넣는다 (번역하거나 줄이지 않는다).
3. 여러 장이 나오면 아래 기준으로 **가장 나은 한 장**을 고른다:
   - 배경이 **순수한 흰색**이다 (종이 무늬·색 배경·그림자 번짐이 화면 끝까지 퍼지지 않음)
   - 물건이 **하나만**, 가운데에, 잘리지 않고 전부 보인다
   - 테두리가 **갈색 색연필 선**이고 검은 선이 아니다
   - 글자·액자·다른 물건이 없다
   - 설명한 모양·개수가 맞다 (예: 꽃잎 5장, 해바라기 꽃잎 12장, 조개 결 5줄)
4. 기준에 맞는 것이 없으면 같은 지시문으로 **한 번 더** 뽑는다. 두 번 해도 안 되면 그나마 나은 것을 저장하고 기록에 '확인 필요'라고 적는다.
5. 고른 그림을 원본 크기로 내려받아 정한 폴더·이름으로 저장한다.

### 화풍 맞추기 (중요)
- **사과(apple)를 가장 먼저** 만든다. 사과가 마음에 들 때까지 다시 뽑는다.
- 사과를 고른 뒤부터는, 그록에 **사과 그림을 참고 이미지로 함께 올리고** 지시문 앞에 이 문장을 붙인다:
  `Use the attached apple as the style reference: same watercolor style, same outline color and thickness, same soft shadow, same white background.`
- 루루 표정 그림은 `lulu-default` 를 먼저 만들고, 나머지 표정은 **lulu-default 를 참고 이미지로 올려** 같은 캐릭터로 표정만 바꾼다:
  `Same character as the attached image, same proportions and colors, only change the expression and pose:`

### 공통 문구 (모든 지시문 끝에 붙인다)
```
STYLE: cute children's storybook watercolor illustration, soft hand-painted watercolor washes with visible paper grain, warm brown colored-pencil outline (#6B5444, slightly wobbly, rounded ends, never black), light coming from the top-left with one soft white highlight on the upper left, a faint light-brown oval shadow on the ground under the object, gentle pastel palette (sage green #A8C3A0, cream #FFF5DF, petal pink #F3C6D2, apricot #F5D0AD, mist blue #C8DFE8, soft lilac #D9D0EC, oak #B9855A), simple shapes with 2-3 main color areas, single object centered, front view or slightly from above, isolated on a pure white background, no text, no frame, no border, no extra objects.
AVOID: black outlines, pure black, neon or saturated colors, photorealism, 3D render, glossy plastic look, gradients that look digital, busy details, background scenery, paper texture in the background, cast shadows to the side, text or letters.
```
- 표에 **[얼굴]** 이 붙은 것은 지시문 끝에 `smiling friendly face, rosy pink cheeks.` 를 덧붙인다.
- 표에 **[그림자 없음]** 이 붙은 것은 공통 문구의 그림자 부분 대신 `floating, no ground shadow.` 를 덧붙인다.

### 진행 기록
- 저장 폴더에 `기록.txt` 를 만들고 한 장 끝날 때마다 한 줄씩 적는다: `파일 이름 | 저장함 / 확인 필요 | 짧은 메모`
- 그록이 막히거나(사용 한도, 로그인 풀림) 오류가 나면 멈추고 어디까지 했는지 나에게 알려 준다. 사용 한도에 걸리면 기다리지 말고 멈춘다.
- 결제·구독·설정 변경은 하지 않는다.
