# 루루 목소리 녹음 — 클로드 웹에 붙여 넣을 지시문

아래 '지시문' 부분을 클로드 웹(브라우저를 조작할 수 있는 클로드)에 붙여 넣으면, ElevenLabs 웹사이트에서 셈셈마을 한국어 대사 **489문장**을 루루 목소리(Ajin)로 하나씩 녹음해 PC 의 로드투리즈 폴더에 번호 이름으로 저장합니다.

- 문장이 많으니 **묶음(100문장씩)으로 나눠** 시키세요. 처음에는 **1묶음(001~100)** 만 시켜 보고, 소리를 들어 본 뒤 나머지를 시키는 것을 추천합니다.
- 크레딧: 1글자에 약 1크레딧, 모두 약 9,051자 → **약 9,000크레딧** (다시 뽑은 만큼 더 듭니다).
- 다 되면 `셈셈마을_목소리` 폴더를 압축해 셈셈마을 작업 대화에 올려 주세요. 소리 다듬기와 앱에 넣기는 제가 합니다.
- 번호와 문장의 짝은 저장소 `docs/voice/ko-lines.json` 에 있습니다 (문장을 고치면 번호가 바뀌므로, 이 목록으로 녹음한 파일은 이 목록과 함께 씁니다).

## 지시문 (여기부터 복사)

너는 지금부터 내 PC 의 브라우저에서 **ElevenLabs 웹사이트(elevenlabs.io)** 로 아이용 수학 게임 '셈셈마을'의 한국어 대사를 녹음해 저장하는 일을 한다. 아래 규칙대로 한 문장씩 차례로 진행해.

### 저장 위치와 파일 이름
- 내 PC 의 **로드투리즈** 폴더 안에 `셈셈마을_목소리/ko` 폴더를 만들고 그 안에 저장한다.
  - 예: `로드투리즈/셈셈마을_목소리/ko/001.mp3`
- 파일 이름은 아래 표의 **파일** 칸 그대로 (세 자리 번호 + `.mp3`). 번호를 바꾸거나 건너뛰지 않는다.
- 같은 문장을 다시 녹음하면 덮어쓴다.

### ElevenLabs 설정 (처음 한 번)
1. elevenlabs.io 에 로그인된 상태로 **Text to Speech** 화면을 연다.
2. 목소리: **Ajin** (이름에 'Ajin-Natural, Clear, Bright, Sweet, Soft, Lovely' 가 들어간 한국어 여성 목소리, Voice ID `XfOUWwmaVeeoarsTYigF`).
   - 목록에 없으면 Voice Library 에서 'Ajin' 을 찾아 **Add to my voices** 로 추가한다.
3. 모델: **Eleven v3** (없으면 Eleven Multilingual v2). 언어를 고를 수 있으면 **Korean**.
4. 목소리 설정(안정성·유사도 등)은 **기본값 그대로** 두고, 녹음하는 동안 바꾸지 않는다 (문장마다 목소리가 달라지지 않게).
5. 출력 형식을 고를 수 있으면 **MP3** (44.1kHz, 128kbps 정도면 충분).

### 녹음 방법
1. 표의 **문장**을 글자 그대로 붙여 넣는다. 고치거나, 덧붙이거나, 문장부호를 바꾸지 않는다 (… ! ? 도 그대로).
2. 생성한 소리를 한 번 들어 보고 아래에 맞으면 내려받아 정한 이름으로 저장한다:
   - 문장을 **빠짐없이** 읽었다 (끝이 잘리지 않음)
   - 밝고 부드러운 말투이고, 이상한 소리·잡음·다른 언어 발음이 없다
3. 맞지 않으면 **한 번만** 다시 생성한다. 그래도 이상하면 나은 것을 저장하고 기록에 '확인 필요'라고 적는다.
4. 숫자는 쓰인 대로 읽게 둔다. 단, 시계 문장에서 '4시'를 '사 시'로 읽는 등 **명백히 틀리게 읽으면** 기록에 '발음 확인'이라고 적는다 (문장은 고치지 않는다).

### 진행 기록
- `셈셈마을_목소리/ko/기록.txt` 에 한 문장마다 한 줄: `번호 | 저장함 / 확인 필요 / 발음 확인 | 짧은 메모`
- 사용 한도·크레딧 부족·로그인 풀림·오류가 나면 **멈추고** 어디까지 했는지 알려 준다. 결제·요금제 변경은 하지 않는다.
- 내가 말한 묶음이 끝나면 멈추고, 저장한 파일 수와 '확인 필요' 목록을 알려 준다.

### 공통 주의
- 목록에 없는 문장은 녹음하지 않는다.
- 파일 하나에 한 문장만 담는다.
