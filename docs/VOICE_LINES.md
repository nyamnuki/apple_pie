# 듣기용 문장 (초안)

화면 글자는 그대로 두고, **소리로 들려줄 때만** 쓰는 문장입니다. 모든 소리를 AI 목소리(ElevenLabs) 하나로 미리 녹음해 앱에 넣고, 기기 음성은 쓰지 않습니다.

## 녹음 방식

| 종류 | 어떻게 | 예 |
|---|---|---|
| 늘 같은 문장 | 화면 글 그대로 녹음 | 발견하기 설명, "다시 해 볼까요?", 놀이·가구 이름, 마을 소개 |
| 살펴보기·만져 보기 장면 | 이 장면은 늘 같으므로 수를 채운 문장 그대로 녹음 | "화분에 꽃이 8송이 있어요. 꽃 5송이가 더 기다리고 있어요!" |
| 경우가 적은 문장 | **모든 경우**를 녹음 | 시계 1~12시, 몇 번째(첫 번째~다섯 번째), 도형(세모·네모), 재는 물건 3가지, 친구 인사 4가지 |
| 수·물건이 바뀌는 문제 | 수·물건 이름을 뺀 **짧은 문장** (아래 표) | 화면: "무당벌레가 7마리 있어요. 9마리가 더 날아와요. 모두 몇 마리가 될까요?" → 소리: "더 날아오면 모두 얼마나 될까요?" |
| 셀 때 | 수 1~100 을 하나씩 | "하나, 둘, 셋…" / "one, two, three…" |

- 물건마다 세는 말이 달라서(개·마리·송이) 소리로는 "**얼마나**"를 씁니다.
- 수는 그림에 보이므로 문제를 이해하는 데 지장이 없습니다.
- 정답 문장은 "맞아요! 잘 세었어요."처럼 칭찬만 들려줍니다 (정답 수는 화면에 크게 보입니다).

## 바뀌는 문제의 듣기용 문장

| 놀이 · 단계 | 한국어 | English |
|---|---|---|
| **사과 세기** 예상 | 모두 얼마나 있을 것 같아요? | How many do you think there are? |
| 확인 | 하나씩 세어 볼게요… 마지막에 말한 수가 모두예요! | Let's count them one by one… the last number we say is how many there are! |
| 해 보기 | 모두 얼마나 있을까요? | How many are there? |
| 힌트 1 | 천천히 살펴봐요. 하나씩, 한 번만 세었나요? | Look carefully. Did you count each one just once? |
| 힌트 2 | 하나씩 눌러서 세어 봐요. 숫자가 나타나요! | Tap each one to count it. Watch the numbers! |
| 정답 | 맞아요! 잘 세었어요. | Yes! Great counting. |
| **어느 쪽이 더 많을까** 예상 | 어느 쪽이 더 많을 것 같아요? | Which group do you think has more? |
| 확인 | 짝을 지어 볼게요… 남는 것이 없어요. 둘은 똑같아요! | Let's make pairs… nothing is left over. They are the same! |
| 해 보기 | 어느 쪽이 더 많을까요? | Which group has more? |
| 힌트 1 | 천천히 살펴봐요. 모두 짝이 있을까요? | Look carefully. Can every one find a partner? |
| 정답 | 맞아요! 남는 쪽이 더 많아요. | Yes! The group with some left over has more. |
| **더하기** 예상 | 더 날아오면 모두 얼마나 될까요? | More are coming. How many will there be? |
| 확인 | 날아왔어요! 처음 수에서부터 이어서 세어 봐요. | Here they come! Start from the first number and count on. |
| 해 보기 | 더 오면 모두 얼마나 될까요? | More come over. How many are there now? |
| 힌트 1 | 천천히 살펴봐요. 처음에 통나무 위에 얼마나 있었나요? | Look carefully. How many were on the log at the start? |
| 힌트 2 | 오고 있는 것을 하나씩 눌러 봐요. 이어서 세어요! | Tap each one that is coming over. Count on as they join! |
| 정답 | 맞아요! 이어서 세니까 금방이에요. | Yes! Counting on makes it quick. |
| **빼기** 예상 | 날아가고 나면 얼마나 남을까요? | Some fly away. How many will be left? |
| 확인 | 훨훨 날아갔어요! 남아 있는 것을 세어 봐요. | Off they go! Let's count the ones still here. |
| 해 보기 | 루루가 먹고 나면 얼마나 남을까요? | Lulu eats some. How many are left? |
| 힌트 1 | 천천히 살펴봐요. 루루는 얼마나 먹을까요? | Look carefully. How many will Lulu eat? |
| 힌트 2 | 루루가 먹을 것을 눌러 보고, 남은 것을 세어 봐요. | Tap the ones Lulu eats, then count what is left. |
| 정답 | 맞아요! 남은 것을 잘 세었어요. | Yes! You counted what was left. |
| **몇 개 더 많을까** 예상·해 보기 | 하나씩 짝을 지으면, 짝이 없는 것은 얼마나 될까요? | If we pair them up, how many have no partner? |
| 확인 | 줄을 세워 볼게요… 짝이 없는 만큼 더 많아요! | Let's line them up… the ones with no partner show how many more! |
| 힌트 1 | 하나씩 짝을 짓는다고 생각해 봐요. 남는 것은 얼마나 될까요? | Imagine making pairs. How many are left over? |
| 힌트 2 | 직접 줄을 세워 봐요. 눌러요! | Line them up yourself. Tap them! |
| 정답 | 맞아요! 짝이 없는 만큼 더 많아요. | Yes! That's how many more. |
| **다음에 올 것은?** 예상·해 보기 | 되풀이되는 규칙을 봐요. 다음엔 무엇이 올까요? | Look at the repeating pattern. What comes next? |
| 확인 | 되풀이되는 부분을 처음부터 다시 말해 봐요… 다음이 보여요! | Say the repeating part again from the start… now you can see what comes next! |
| 정답 | 맞아요! 규칙이 다시 시작돼요. | Yes! The pattern starts again. |
| **줄을 선 친구들** (첫 번째~다섯 번째 모두 녹음) | 이 줄을 봐요. 앞에서 두 번째는 누구일까요? … | Look at this line. Who is number two from the front? … |
| **도형 찾기** (세모·네모 따로 녹음) | 이번엔 세모를 찾아봐요. 세모는 몇 개일 것 같아요? … | Now find the triangles. How many do you think there are? … |
| 확인 | 세모를 세어 볼게요… 돌아가 있는 것도 세모예요! | Let's count the triangles… even the turned ones are triangles! |
| 정답 | 맞아요! 돌아가 있는 것도 세모예요! | Yes! Even the turned ones are triangles! |
| **얼마나 길까** (나뭇가지·리본·애벌레 따로 녹음) | 이번엔 리본이에요. 리본은 블록 몇 개만큼 길까요? | Now look at the ribbon. How many blocks long is it? |
| 확인 | 블록을 빈틈없이 놓아 볼게요… 블록 수가 길이예요! | Let's put the blocks under it with no gaps… the number of blocks is the length! |
| 정답 | 맞아요! 블록을 잘 세었어요. | Yes! You counted the blocks. |
| **2씩 뛰어 세기** 예상 | 둘씩 짝지어 있어요. 모두 얼마나 될까요? | They are in pairs. How many are there in all? |
| 확인 | 2씩 세어 볼게요… 2, 4, 6… | Let's count by twos… 2, 4, 6… |
| 해 보기 | 둘씩 짝지어 있는데, 하나는 혼자예요. 모두 얼마나 될까요? | They are in pairs, but one is all alone. How many in all? |
| 힌트 2 | 짝마다 누르면서 2씩 세어 봐요. 마지막에 혼자 있는 것을 눌러요. | Tap each pair and count by twos. Then tap the lonely one. |
| 정답 | 맞아요! 짝을 2씩 세고 하나를 더했어요. | Yes! Pairs by twos, then one more. |
| **5씩 뛰어 세기** 예상 | 다섯씩 모여 있어요. 모두 얼마나 될까요? | They are in groups of five. How many in all? |
| 확인 | 5씩 세어 볼게요… 5, 10, 15… | Let's count by fives… 5, 10, 15… |
| 해 보기 | 다섯씩 모여 있고, 몇 개는 따로 있어요. 모두 얼마나 될까요? | Groups of five, and a few on their own. How many in all? |
| 힌트 2 | 묶음마다 누르면서 5씩 세어 봐요. 마지막에 따로 있는 것을 눌러요. | Tap each group and count by fives. Then tap the single ones. |
| 정답 | 맞아요! 5씩 세고, 따로 있는 것을 이어 셌어요. | Yes! Fives first, then the single ones. |
| **10씩 묶어 세기** 예상 | 10개짜리 상자와 낱개가 있어요. 모두 얼마나 될까요? | There are boxes of ten and some loose ones. How many in all? |
| 확인 | 세어 볼게요. 10, 20, 30… 그다음 낱개를 세요. | Let's count: 10, 20, 30… then the loose ones. |
| 해 보기 | 모두 얼마나 있을까요? | How many are there? |
| 정답 | 맞아요! 10묶음을 먼저 세고, 낱개를 셌어요. | Yes! Tens first, then the ones. |
| **수직선 뛰기** 예상 | 왼쪽으로 뛰면 어디에 닿을까요? | If the frog hops to the left, where will it land? |
| 확인 | 왼쪽으로 한 칸씩 뛰어 볼게요… | Let's hop to the left, one space at a time… |
| 해 보기 | 오른쪽으로 뛰면 어디에 닿을까요? | If the frog hops to the right, where will it land? |
| 정답 | 맞아요! 뛴 만큼 더했어요. | Yes! You added the hops. |
| **짝수·홀수** 예상 | 모두 짝이 되면 짝수, 하나가 남으면 홀수예요. 어느 쪽일까요? | Even means everyone has a partner. Odd means one is left over. Which is it? |
| 확인 | 짝을 지어 볼게요… 남는 것이 있나요? | Let's make pairs… is one left over? |
| 해 보기 | 짝수일까요, 홀수일까요? | Even or odd? |
| 힌트 1 | 둘씩 짝지어 본다고 생각해 봐요. 하나가 남나요? | Imagine putting them in pairs. Is one left over? |
| 힌트 2 | 직접 짝을 지어 봐요. 눌러요! | Make the pairs yourself. Tap them! |
| 정답 | 맞아요! 잘 짝지었어요. | Yes! Great pairing. |
| **10 만들기** 예상·해 보기 | 상자를 꽉 채우면 10이에요. 얼마나 더 있으면 10이 될까요? | A full box is 10. How many more make 10? |
| 확인 | 빈칸을 채워 볼게요… 빈칸 수만큼 더 있으면 10이에요! | Let's fill the empty spots… that many more make 10! |
| 정답 | 맞아요! 모두 10이에요. | Yes! That makes 10. |
| **시계** (1~12시, 30분 모두 녹음) | 긴바늘이 12에, 짧은바늘이 3에 있어요. 세 시예요! … | The long hand is on 12 and the short hand is on 3. It's three o'clock! … |
| **똑같이 나누기** 예상·해 보기 | 두 친구가 똑같이 나누면, 한 친구가 얼마나 가질까요? | If two friends share fairly, how many does each get? |
| 확인 | 하나씩 번갈아 나눠 볼게요… 둘이 똑같아요! | Let's share them one at a time… now they are the same! |
| 힌트 1 | 두 친구에게 하나씩 번갈아 준다고 생각해 봐요. | Imagine giving one to each friend, again and again. |
| 힌트 2 | 직접 나눠 봐요. 눌러요! | Share them yourself. Tap them! |
| 정답 | 맞아요! 똑같이 나눴어요. | Yes! A fair share. |
| **두 배** 예상 | 물에도 하나씩 비쳐요. 모두 얼마나 될까요? | Each one shows in the water. How many in all? |
| 확인 | 물에 비친 모습을 볼게요… 같은 수가 한 번 더 있어요! | Let's see the reflections… the same number again! |
| 해 보기 | 물에 비친 것까지 모두 얼마나 될까요? | With the reflections, how many in all? |
| 힌트 1 | 하나마다 물속에 짝이 있어요. 호숫가를 세고, 한 번 더 세어 봐요. | Each one has a twin in the water. Count the shore, then count again. |
| 힌트 2 | 직접 물에 비춰 봐요. 눌러요! | Make the reflections yourself. Tap them! |
| 정답 | 맞아요! 두 배예요. | Yes! That's double. |
| **방 꾸미기** 세기 정답 | 맞아요! 우리 방을 세어 봤어요! | Yes! We counted our room! |
| 새 마을 | 새 마을에 갈 수 있어요! 가 볼까요? | A new place is open! Shall we go? |
| 놓을 가구 | 가방에 있는 것을 방에 놓아 볼까요? | Something is waiting in your bag. Shall we put it in the room? |
| 만들 수 있음 | 재료가 모였어요! 공방에서 만들 수 있어요. | You have the materials! You can make something in the workshop. |

## 예상 크레딧 (ElevenLabs, 1글자 ≈ 1크레딧, 2026-11-26 견적)

| | 한국어 | 영어 |
|---|---|---|
| 늘 같은 문장 (놀이 설명·안내·이름·마을 소개) | 약 3,800자 | 약 7,500자 |
| 살펴보기 장면 (수를 채운 그대로) | 약 900자 | 약 1,800자 |
| 바뀌는 문제의 듣기용 문장 + 모든 경우 녹음 (시계·몇 번째·도형·재는 물건·친구 인사) | 약 4,600자 | 약 8,300자 |
| 셀 때 수 1~100 | 약 200자 | 약 1,000자 |
| **합계 (한 번씩)** | **약 9,500** | **약 18,600** |

- 한 번씩 녹음: **약 28,000크레딧**
- 목소리 고르기(후보 3~4개 × 두 언어 × 시범 문장): 약 1,000크레딧
- 어색한 문장 다시 뽑기(약 15%): 약 4,000크레딧
- **예상 합계: 약 33,000크레딧** (견적 단가로 약 6달러). 모든 문장을 2개씩 뽑아 고르면 약 60,000크레딧.
- 한국어만 먼저 하면 약 12,000크레딧.
