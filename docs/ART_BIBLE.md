# Math Town 그림 규칙 (Art Bible)

수채화 동화책 속 숲속 오두막을 아이소메트릭 방 꾸미기 게임으로 옮긴 모습을 목표로 합니다.
모든 그림은 **같은 종이 위에 같은 사람이 칠한 것처럼** 보여야 합니다.

> 현재 상태 (2026-10): 이 저장소에서는 이미지 생성 도구를 쓸 수 없어서, 모든 그림을 **코드로 그린 SVG + 수채화 효과(SVG 필터)** 로 만들었습니다.
> 손으로 그린 PNG 그림을 `public/assets/` 에 넣으면 그 그림이 SVG 대신 쓰입니다 (이름 규칙은 `public/assets/README.md`).
> 그림을 한눈에 보려면 앱 주소 끝에 `#gallery` 를 붙이세요 (예: `http://localhost:5173/#gallery`). 화면 사진은 `docs/art/`.

## 1. 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| Sage green | `#A8C3A0` | 잎, 풀, 망토, 놀이 버튼 |
| Light moss | `#D5E4C8` | 언덕, 부드러운 바탕 |
| Warm cream | `#FFF5DF` | 종이, 카드, 털 밝은 부분 |
| Oak wood | `#B9855A` | 가구 나무, 창틀, 걸레받이 |
| Petal pink | `#F3C6D2` | 꽃, 볼, 이불 |
| Apricot | `#F5D0AD` | 꽃 가운데, 따뜻한 빛 |
| Mist blue | `#C8DFE8` | 하늘, 물방울, 수정 |
| Soft lilac | `#D9D0EC` | 밤, 나비, 보석 |
| Warm brown | `#59483C` | 글자, 눈 |
| 색연필 선 | `#6B5444` | 모든 그림의 테두리 (검은 선 금지) |

- 진한 색은 사과 빨강 `#E0796B`, 나무 그늘 `#8F613C` 정도까지만. 형광색·순수한 검정은 쓰지 않습니다.
- 글자를 올리는 나무색 버튼은 대비를 위해 `#946539`(wood) 를 씁니다.

## 2. 시점과 비율
- 방과 가구: **2:1 아이소메트릭**. 바닥 한 칸 = 가로 120 × 세로 60 (방 좌표). 방은 6×6 칸, 벽 높이 220.
- 가구의 기준점은 차지한 바닥 영역의 **맨 아래 꼭짓점**. PNG 로 그릴 때는 그림의 아래 가운데가 이 점에 오게 합니다.
- 벽 장식은 정면에서 본 모양 (가로 100×칸 수, 세로 = 거는 높이 띠). 게임이 벽 각도로 기울입니다.
- 물건·재료 아이콘은 64×64 칸 안에, 아래에 옅은 그림자 타원. 정면 또는 살짝 위에서 본 모습.
- 캐릭터는 120×150 칸. 머리 지름 ≈ 몸 높이 (2등신에 가까운 아기 비율), 머리 가운데 (60, 72) 에 얼굴.

## 3. 빛과 그림자
- 빛은 **왼쪽 위**에서 옵니다.
  - 아이소메트릭 상자: 윗면 = 원래 색 + 왼쪽 위 빛 한 겹, 왼쪽 면 = 조금 어둡게, 오른쪽 면 = 더 어둡게.
  - 둥근 것(머리·몸·가방): `#wc-ball` 그라데이션을 덧칠 (왼쪽 위 밝음 → 오른쪽 아래 가장자리 옅은 그늘).
  - 아이콘: 왼쪽 위에 흰색 반투명 물감 자국 하나.
- 그림자는 바닥에 닿는 옅은 갈색 타원·마름모 (`#59483C`, 불투명도 12~15%). 딱딱한 그림자는 쓰지 않습니다.

## 4. 선과 질감
- 테두리는 갈색 색연필 느낌: `#6B5444`, 굵기 1.6(아이콘)·2(캐릭터)·2~2.5(가구), 끝은 둥글게.
- 수채화 효과는 `src/components/art/WatercolorDefs.tsx` 의 필터 세 가지:
  - `#wc-small` — 아이콘·캐릭터·도형
  - `#wc-furniture` — 가구·벽 장식
  - `#wc-room` — 방 배경·타이틀 풍경
  - 효과 내용: 가장자리 흔들림, 물감이 고인 진한 테두리, 옅은 물감 알갱이.
- 나무 가구 옆면에는 가는 나뭇결 2~3줄. 종이 결은 화면 전체에 아주 옅게 (`.paper-grain`).
- 효과는 **더하지 말고 덜어내는 쪽**으로: 아이가 물건을 세고 구별하는 데 방해되면 안 됩니다. 수학 장면 칸은 장식 없이 크림색 바탕만.

## 5. 캐릭터
| | 모습 | 상징 (모든 화면에서 유지) |
|---|---|---|
| 루루 (토끼) | 크림색 털, 긴 귀 (오른쪽 귀 끝이 살짝 접힘), 분홍 볼 | 잎사귀 망토 + 도토리 단추, 귀에 꽂은 분홍 꽃 |
| 도토 (고슴도치) | 동그란 몸, 두 겹 갈색 가시, 공방 주인 | 동그란 안경, 도토리 가방과 초록 끈 |
| 모모 (다람쥐) | 주황빛 털, 머리 위까지 말려 올라간 큰 꼬리 | 세이지색 스카프, 비스듬한 도토리 모자 |

- 표정 5가지: default · happy · thinking · cheer · surprised. 눈·입은 공용 `Face.tsx` (가장 진한 갈색, 또렷하게).
- 틀린 답에도 화난 표정은 없습니다 (cheer = 응원).

## 6. 화면 (UI)
- 바탕: 크림색 종이 + 은은한 그라데이션 + 종이 결. 카드: `.storybook-card` (크림 종이, 옅은 테두리, 부드러운 그림자, 오른쪽 위 작은 풀잎).
- 버튼: 아래 그림자 5px + 위쪽 안쪽 빛 한 줄 (만질 수 있을 것 같은 느낌). 최소 높이 56px.
  - 나무색(primary) = 그 화면에서 가장 중요한 한 가지
  - 초록(sage) = 놀이·이동
  - 크림(soft) = 보조
- 누를 수 없는 버튼: 평평한 회갈색 + 점선 테두리 (색만으로 알리지 않음).
- 진행 표시: 잎사귀 6장 (지난 단계는 칠함, 지금 단계는 크게).
- 아이콘: 지금은 lucide 선 아이콘(둥근 끝)을 갈색으로 씁니다. 손으로 그린 아이콘으로 바꿀 후보는 7장의 '남은 일'을 보세요.

## 7. 이름 규칙 (그림 파일)
- `public/assets/<폴더>/<소문자-이름>.png` — 예: `furniture/leaf-bed.png`, `items/res-moon-dew.png`, `characters/lulu-happy.png`
- 투명 배경 PNG, 2배 크기로 그려도 됩니다. 이름을 틀리면 `npm run test:unit` 이 알려줍니다.

## 8. 남은 일 (전용 그림이 있으면 좋은 것)
- 모든 그림이 코드 SVG 입니다. 손그림 수채화 PNG 가 생기면 가장 먼저 바꾸면 좋은 순서:
  1. 방 배경 `room-base.png`
  2. 캐릭터 15장
  3. 침대·러그·조명
  4. 나머지 가구
  5. 물건·재료
- 버튼 아이콘(설정, 뒤로, 망치 등)은 아직 lucide 선 아이콘입니다.
- 지도는 카드 목록입니다. 숲길이 그려진 그림 지도로 바꾸면 더 동화책 같아집니다.
